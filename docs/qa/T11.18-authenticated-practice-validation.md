## Exact application eligibility

The Practice Stuwy entry is rendered only when all of these hold:

1. The user is authenticated (`user.id` is present).
2. The Practice subject slug resolves to Maths/Mathematics and the active level is CM1.
3. The topic is returned by the existing curriculum Practice topic query and its label is a subtraction topic or a four-operations topic.
4. That topic has an active `quiz_bank_assignments` row exposed by Practice's assignment map.
5. `useAllBanks(topic.id, ..., userId, 'practice')` returns the same topic with an unlocked bank.

The staging assignment meets conditions 2–5. The original label matcher accepted only “soustraction”; it rejected the verified “Les quatre opérations” topic even though its assigned CM1 Practice bank includes subtraction material. I corrected that narrow mismatch and added a test. The gate still requires an active Practice assignment and the authenticated, unlocked-bank checks above.

# T11.14 — Pedagogical corrections QA

## Scope

Validated the Teacher Engine return path after a demonstration and targeted remediation for compensation versus arithmetic errors. The original `TwoCards.tsx`, `CompactMathStepper.tsx`, and shared mathematics engine were not modified.

## Changes

- Demonstrations now retain the current tutoring stage, exact prompt, prior feedback, attempts, hint state, completed stages, and response draft. Returning from the animation restores the same question; it does not jump over unfinished steps.
- Wrong responses record an error kind (`compensation` or `arithmetic`). The remediation practice is selected for both the active column and the diagnosed difficulty; solving it returns to the original prompt.
- Feedback and hints distinguish an omitted compensation adjustment from an arithmetic calculation error. The final-result hints avoid exposing `169` before submission.
- Clearing the answer draft is tied to a real question/prerequisite change, not to transient feedback/demo states.
